# 🥚🔍 ภารกิจนักสืบไข่เป็ดปริศนา: คำผิด คำถูกต้อง

เกมฝึกสะกดคำภาษาไทยสำหรับนักเรียน ป.5 ในธีมนักสืบ มีมาสคอต "ไข่เป็ดนักสืบ" (ออกแบบใหม่ วาดด้วย SVG)
เล่นต่อเนื่อง 3 ภารกิจ แล้วสรุปผลใน "สมุดบันทึกนักสืบ" ที่พิมพ์ออกมาได้

| ภารกิจ | ชื่อ | วิธีเล่น | จำนวนข้อ |
|---|---|---|---|
| 1 | คนไหนคนถูก | แตะเลือกคำที่เขียนถูกจาก 2 คำ | 8 |
| 2 | จับตัวอักษร | อ่านคำใบ้ แล้วหยิบตัวอักษรมาเรียงเป็นคำ (ใช้มือผ่านกล้อง หรือเมาส์/นิ้วสัมผัส) | 5 |
| 3 | นักสืบคำผิด | แตะจับ "คนร้าย" คือคำที่เขียนผิด 1 คำจาก 4 คำ | 8 |

คะแนน: ภารกิจ 1 และ 3 ข้อละ 10 คะแนน ภารกิจ 2 ข้อละ 20 คะแนน (เต็ม 260)
ดาวตอนจบ: ได้ 80% ขึ้นไป 3 ดาว, 50% ขึ้นไป 2 ดาว, ต่ำกว่านั้น 1 ดาว

---

## 1. ติดตั้งและเปิดเกม

ต้องมี [Node.js](https://nodejs.org/) เวอร์ชัน 18 ขึ้นไป

```bash
cd duck-egg-detective
npm install
npm run dev
```

แล้วเปิด **http://localhost:5173** ในเบราว์เซอร์ (แนะนำ Chrome หรือ Edge)

คำสั่งอื่นๆ
- `npm run build` สร้างไฟล์สำหรับนำขึ้นเว็บไว้ในโฟลเดอร์ `dist/`
- `npm run preview` เปิดดูไฟล์ที่ build แล้ว
- `npm run dev:lan` เปิดให้เครื่องอื่นในวง LAN เข้ามาเล่นได้ (ดูหมายเหตุเรื่องกล้องในข้อ 5)

> **ไม่มี Node.js?** เกมนี้เป็น static web ล้วน (vanilla JS แบบ ES modules) เปิดด้วยเซิร์ฟเวอร์อะไรก็ได้ เช่น
> `python3 -m http.server 8000` ในโฟลเดอร์นี้ แล้วเปิด http://localhost:8000
> (ห้ามดับเบิลคลิกเปิดไฟล์ `index.html` ตรงๆ เพราะโมดูล JS และกล้องจะใช้ไม่ได้)

ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ (Mali, Sarabun) และตัวตรวจจับมือ MediaPipe (ภารกิจ 2)

## 2. วิธีเล่น (สำหรับครู/นักเรียน)

1. พิมพ์ชื่อนักเรียน แล้วกด **🔍 เริ่มภารกิจ**
2. เล่นภารกิจ 1 → 2 → 3 ตามลำดับ แถบด้านบนแสดงคะแนนรวมและดาว ★ ของแต่ละภารกิจ
3. ทุกครั้งที่ตอบผิด คำนั้นจะถูกบันทึกลงสมุดทันที
4. จบภารกิจ 3 จะเห็นคะแนน ดาว และ **สมุดบันทึกนักสืบ** (ภารกิจที่ผิด / สิ่งที่นักเรียนเลือกหรือเขียน / คำที่ถูกต้อง / หลักการสะกด)
5. ปุ่มในหน้าสรุป
   - **🔁 เล่นภารกิจซ้ำเฉพาะคำที่ผิด** – ทบทวนแบบภารกิจ 1 เฉพาะคำที่เคยผิด (ไม่นับคะแนน)
   - **🖨️ พิมพ์/บันทึกสมุด** – พิมพ์หรือบันทึกเป็น PDF (เลือก "Save as PDF" ในหน้าต่างพิมพ์)
   - **👫 เริ่มใหม่ให้เพื่อนคนต่อไป** – ล้างชื่อ คะแนน สมุด และปิดกล้อง กลับหน้าแรก
6. ปุ่ม 🔊/🔇 มุมขวาบนใช้ปิด/เปิดเสียง ปุ่ม 🏠 ใช้เริ่มใหม่ระหว่างเล่น

### ภารกิจ 2 แบบใช้กล้อง
- นั่งห่างจอประมาณ 1 ช่วงแขน ให้กล้องเห็นมือชัด (ใช้มือข้างไหนก็ได้ รองรับสูงสุด 2 มือพร้อมกัน)
- ทำนิ้วโป้งกับนิ้วชี้ประกบกัน 🤏 ใกล้ตัวอักษร = **หยิบ** → ขยับไปที่ช่อง → แยกนิ้ว = **ปล่อย**
- ถ้าปล่อยไม่ใกล้ช่อง ตัวอักษรจะกลับที่เดิม ถ้าวางทับช่องที่มีตัวอักษรอยู่แล้วจะสลับกัน
- จับ 🤏 ที่ปุ่มเพื่อกดปุ่มได้ (เช่น "ตรวจคำตอบ", "ข้อต่อไป")
- วงกลมสีฟ้าคือตำแหน่งนิ้ว จะเปลี่ยนเป็นสีส้มเมื่อกำลังหยิบ

### ภารกิจ 2 แบบเมาส์/นิ้วสัมผัส
- ลากตัวอักษรไปวางในช่อง หรือแตะตัวอักษรเพื่อใส่ช่องว่างถัดไป
- แตะตัวอักษรในช่องเพื่อนำออก / ปุ่ม "ล้างช่อง" นำออกทั้งหมด
- ถ้าเปิดกล้องไม่ได้ เกมจะเปลี่ยนมาโหมดนี้ให้อัตโนมัติ

สระบน สระล่าง และวรรณยุกต์เป็นตัวอักษร 1 ตัวต่อ 1 ช่อง (แสดงบนตัว "อ" สีจางเพื่อให้มองเห็นชัด)

## 3. ความเป็นส่วนตัว

- ภาพจากกล้องประมวลผล **ในเครื่องเท่านั้น** ด้วย MediaPipe (WebAssembly) ไม่มีการบันทึกหรืออัปโหลดภาพไปที่ใด
  (อินเทอร์เน็ตใช้แค่ดาวน์โหลดไฟล์ไลบรารีและโมเดล ไม่ได้ส่งภาพออกไป)
- กล้องจะปิดทันทีเมื่อจบภารกิจ 2, เปลี่ยนไปโหมดเมาส์, กดเริ่มใหม่ หรือกลับหน้าแรก
- ไม่เก็บข้อมูลนักเรียนข้ามคน: ชื่อ คะแนน และสมุดบันทึกอยู่ในหน่วยความจำเท่านั้น (ไม่ใช้ localStorage/cookie) ปิดหรือรีเฟรชหน้าแล้วข้อมูลหายหมด

## 4. เพิ่ม/แก้คำในคลังคำ

แก้ไฟล์ `src/data/words.js` แต่ละคำมีรูปแบบ

```js
{
  correct: 'สังเกต',                 // คำที่ถูก
  wrong: ['สังเกตุ'],                // คำที่เด็กมักเขียนผิด (1 คำขึ้นไป)
  hint: 'ดูอย่างตั้งใจ เช่น นักสืบต้อง____ร่องรอยให้ดี', // คำใบ้ภารกิจ 2 (____ = ช่องว่าง)
  explanation: 'สะกดด้วย ต เต่า ตัวเดียว ไม่มีสระอุใต้ ต',
  category: 'ตัวสะกด',               // ร/ล, สระอุ/อู, สระอิ/อี, ใ/ไ, ตัวสะกด, การันต์, ศ/ษ/ส, คำทั่วไป
},
```

ข้อควรระวัง
- ตรวจการสะกดกับ **พจนานุกรมฉบับราชบัณฑิตยสถาน** (ค้นได้ที่ https://dictionary.orst.go.th/) และไม่ใส่คำที่ยังมีข้อถกเถียง
- คำผิดใน `wrong` ต้องเป็นแบบที่เด็กเขียนผิดจริง และ **ต้องไม่ใช่คำอื่นที่มีความหมาย** (เช่น ห้ามใช้ "สัญญา" เป็นคำผิดของ "สัญญาณ")
- คำใบ้ห้ามมีคำตอบอยู่ในนั้น และห้ามใช้รูปภาพ
- ภารกิจ 2 เลือกเฉพาะคำที่มี 3–8 อักขระให้อัตโนมัติ (นับทีละตัวรวมสระ/วรรณยุกต์ เช่น "ใหญ่" = 4) ปรับได้ที่ `MISSION2_MAX_CHARS`
- ถ้าอยากตรวจคลังคำหลังแก้ ให้เปิดเกมแล้ววางโค้ดนี้ใน Console ของเบราว์เซอร์ (F12)

```js
const { WORDS } = await import('/src/data/words.js');
const all = new Set(WORDS.map(w => w.correct));
WORDS.forEach(w => w.wrong.forEach(x => {
  if (x === w.correct || all.has(x)) console.warn('คำผิดซ้ำกับคำถูก:', w.correct, x);
  if (w.hint.includes(w.correct)) console.warn('คำใบ้เฉลยคำตอบ:', w.correct);
}));
console.log('จำนวนคำ', WORDS.length);
```

## 5. แก้ปัญหากล้อง

| อาการ | วิธีแก้ |
|---|---|
| ปุ่ม "เล่นด้วยกล้อง" กดไม่ได้ / ขึ้นว่าต้องใช้ https | กล้องใช้ได้เฉพาะ `https://` หรือ `http://localhost` เท่านั้น ถ้าเปิดจากเครื่องอื่นผ่าน IP (เช่น `http://192.168.x.x:5173`) กล้องจะใช้ไม่ได้ ให้ build แล้วนำขึ้นเว็บที่เป็น https (เช่น GitHub Pages, Netlify) หรือตั้ง HTTPS ให้ Vite ด้วย `@vitejs/plugin-basic-ssl` |
| "ไม่ได้รับอนุญาตให้ใช้กล้อง" | กดไอคอนกล้อง/แม่กุญแจที่แถบที่อยู่ → อนุญาตกล้อง → รีเฟรชหน้า บน macOS ตรวจ System Settings → Privacy & Security → Camera ว่าอนุญาตเบราว์เซอร์แล้ว |
| "กล้องกำลังถูกใช้งานโดยโปรแกรมอื่น" | ปิด Zoom/Meet/Teams หรือแท็บอื่นที่ใช้กล้องอยู่ |
| "โหลดตัวตรวจจับมือไม่สำเร็จ" | ตรวจอินเทอร์เน็ต (ต้องโหลดไฟล์จาก cdn.jsdelivr.net และ storage.googleapis.com) หรือเก็บไฟล์ไว้ในเครื่องตามหัวข้อถัดไป |
| โหลดนาน | ครั้งแรกต้องดาวน์โหลดประมาณ 10 MB ครั้งต่อไปเบราว์เซอร์จะจำไว้ |
| มองไม่เห็นมือ / เคอร์เซอร์กระตุก | เพิ่มแสงสว่าง ให้มืออยู่ในกรอบภาพ หันฝ่ามือเข้ากล้อง ไม่ใกล้หรือไกลเกินไป |
| หยิบยาก/หยิบง่ายเกินไป | ปรับ `PINCH_ON` / `PINCH_OFF` ใน `src/hooks/useHandPinch.js` (ค่ายิ่งมาก ยิ่งหยิบง่าย) |
| ใช้กล้องไม่ได้เลย | เลือก "เล่นด้วยเมาส์/สัมผัส" เล่นได้ครบทุกอย่างเหมือนกัน |

### ใช้งานแบบไม่ต้องต่ออินเทอร์เน็ต (MediaPipe ในเครื่อง)
1. `npm install @mediapipe/tasks-vision@0.10.14`
2. คัดลอก `node_modules/@mediapipe/tasks-vision/` ทั้งโฟลเดอร์ `wasm/` และไฟล์ `vision_bundle.mjs` ไปไว้ที่ `public/mediapipe/`
3. ดาวน์โหลด [hand_landmarker.task](https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task) ไปไว้ที่ `public/mediapipe/hand_landmarker.task`
4. แก้ค่าคงที่ใน `src/hooks/useHandPinch.js` เป็น
   `VISION_BASE = '/mediapipe'` และ `HAND_MODEL_URL = '/mediapipe/hand_landmarker.task'`
5. ฟอนต์ใช้ Google Fonts ถ้าออฟไลน์เบราว์เซอร์จะใช้ฟอนต์ไทยของเครื่องแทน

## 6. โครงสร้างโปรเจกต์

```
duck-egg-detective/
├─ index.html
├─ package.json
└─ src/
   ├─ main.js               ลำดับหน้าจอ: หน้าแรก → ภารกิจ 1-3 → สรุปผล, รีเซ็ต
   ├─ state.js              สถานะเกมในหน่วยความจำ (ชื่อ คะแนน สมุดบันทึก)
   ├─ styles.css            สไตล์ทั้งหมด รวม print CSS
   ├─ data/words.js         คลังคำ (แก้ไขง่าย)
   ├─ missions/
   │  ├─ mission1.js        คนไหนคนถูก (ใช้ซ้ำในโหมดทบทวน)
   │  ├─ mission2.js        จับตัวอักษร (กล้อง + ลากวาง)
   │  └─ mission3.js        นักสืบคำผิด
   ├─ hooks/useHandPinch.js ตรวจจับมือและท่าจับด้วย MediaPipe (smoothing + hysteresis)
   ├─ components/           มาสคอต, HUD, กล่องผลลัพธ์, สมุดบันทึก, เสียง, เอฟเฟกต์
   └─ utils/thai.js         แยกอักขระไทยด้วย Array.from
```

หลักการตรวจท่าจับ: ระยะปลายนิ้วโป้ง (landmark 4) กับปลายนิ้วชี้ (landmark 8) หารด้วยขนาดมือ
(ข้อมือ 0 → โคนนิ้วกลาง 9) ต่ำกว่า 0.30 = หยิบ, สูงกว่า 0.45 = ปล่อย ต้องเห็นติดกัน 2 เฟรมจึงเปลี่ยนสถานะ
ตำแหน่งเคอร์เซอร์คือจุดกึ่งกลางของ 2 นิ้ว ผ่าน smoothing ที่ปรับตามความเร็วมือ

## 7. สิ่งที่ทดสอบแล้ว / ยังไม่ได้ทดสอบ

ทดสอบแล้ว (Chrome บน macOS, ขนาดจอเดสก์ท็อปและมือถือ 375px)
- ภารกิจ 1, 3 ครบทุกข้อ ทั้งตอบถูกและผิด, คะแนน/ดาว, บันทึกลงสมุด
- ภารกิจ 2 โหมดลากวางและแตะ, การตรวจคำตอบถูก/ผิด, การสลับช่อง
- ภารกิจ 2 โหมดมือ โดยป้อนข้อมูลมือจำลอง (หยิบ ลาก ปล่อย กดปุ่มด้วยท่าจับ) และปิดกล้องเมื่อจบด่าน
- ตรรกะท่าจับกับ landmark จำลอง (มือใกล้/ไกล, hysteresis, มือหาย, 2 มือ, smoothing)
- โหลด MediaPipe + โมเดลจาก CDN และรันตรวจจับได้จริง (GPU)
- กรณีไม่ได้รับอนุญาตกล้อง → เปลี่ยนเป็นโหมดเมาส์อัตโนมัติ
- โหมดทบทวนคำที่ผิด, ปุ่มเริ่มใหม่ (ล้างข้อมูลทั้งหมด), ไม่มีการใช้ localStorage
- ตรวจคลังคำ: ไม่มีคำซ้ำ คำผิดไม่ชนกับคำถูก คำใบ้ไม่เฉลยคำตอบ

ยังไม่ได้ทดสอบ
- **ท่าจับกับกล้องและมือจริง** (ต้องลองกับเด็กจริงเพื่อปรับค่า `PINCH_ON`/`PINCH_OFF`)
- Safari / iPad / Android จริง
- หน้าพิมพ์จริง (ตรวจเฉพาะ print CSS)
- `npm run dev` ด้วย Vite (เครื่องที่พัฒนาไม่มี Node.js จึงทดสอบผ่านเซิร์ฟเวอร์ static แทน โค้ดไม่ต้อง build จึงควรทำงานเหมือนกัน)
